## 配置怎么选：1GB、2GB、4GB 分别对应什么站

WordPress 加 WooCommerce 跑起来，真正先吃紧的通常是内存和磁盘 IO。一个正常优化的外贸站，日访问一两千 PV，2GB 内存、单核就够；流量再往上才需要动 CPU。

**512MB 和 1GB 这两档的实际边界**：1GB 跑 WordPress 加 WooCommerce 能跑，条件是内存占用压在 600MB 以内，重型插件得禁掉，缓存必须配好。512MB 那档不建议拿来做站，5GB 存储装完系统和运行环境后剩不下多少，传几十张产品图就告急，它更适合当中转或监控节点。

**2GB 是性价比最高的一档**。VM-1 的 $5.99 和 VM-1.5 的 $6.95 差不到一美元，后者多一个核。WooCommerce 结账、后台保存文章这类操作会遇到并发，两个核比一个核从容，多花 96 美分买这个余量值。

**4GB 对应多站**。按经验换算，4GB 内存可以稳跑 2 到 3 个轻量 WordPress，6GB 跑 3 到 5 个。做站群的话直接从 VM-2 起步，别用一台 2GB 硬塞三个站，内存一满 MySQL 先挂。

**8GB 以上多数人用不上**。VM-6 是 8 核 8GB，VM-8 是 8 核 16GB，这类配置对应的是同时跑多个 WooCommerce 站点、装了大量插件、或者数据库本身就吃内存的场景。一个月 $29.99 起步，一年三百多美元，一个日 PV 不到五千的展示型外贸站买这个纯属浪费。

## 常见问题

**1GB 内存能跑 WooCommerce 吗？**
能，但要压着用。内存占用控制在 600MB 以内，禁掉重型插件，配好缓存。产品超过 50 个、或者要装多语言插件，直接上 2GB 更省心。

**第二年续费会涨价吗？**
官网价格页标的是标准月价，没有把首年价单独拿出来做促销，公开页面上看不到首年与续费的价格差异。想彻底锁死，买 3 年周期。

**支持支付宝吗？**
不支持。可用的是信用卡、借记卡、PayPal、Bitcoin、USDt（Tron）。

**一台机器能放几个外贸站？**
看内存。2GB 放一个，4GB 放 2 到 3 个轻量站，8GB 放 3 到 5 个。多站建议直接从 VM-2 起。

**客户在美国，机房选哪个国家？**
美国节点。欧洲客户为主就选英国、德国或阿姆斯特丹。别为了自己后台快把站放亚洲，海外客户的加载速度补不回来。

**流量超了会停机吗？**
流量用完可以在控制面板按 TB 加购，标准网络 $3/TB。做图片多的站要提前把流量算进去。
